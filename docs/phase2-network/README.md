# CONNECTA – Phase 2: Packet Tracer Network Prototype
This folder contains the initial IPv4 network prototype developed using Cisco Packet Tracer.
The prototype includes two enterprise sites, DHCP configuration, static routing, Layer-2 switches, and connectivity testing.
Advanced network features such as VLANs, OSPF, EtherChannel, RSTP, NAT, and firewall policies are planned for subsequent phases.
